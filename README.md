# Оно тебе надо

Проектная работа Яндекс Практикума: страница аукциона вещей, в которые никто не верил.

## Запуск

Откройте `index.html` в браузере. Сборка, установка пакетов и подключение к интернету не нужны: все изображения и шрифты хранятся в проекте.

Страница имеет фиксированную ширину 1100 px в соответствии с заданием. Мобильная версия и логика аукциона не входят в эту проектную работу. Кнопка «Сделать ставку» и ссылки карточек оформлены как элементы учебного макета. Навигация по разделам, ссылки телефона, почты и социальных сетей работают.

## Структура

- `index.html` — семантическая разметка всех секций.
- `fonts/` — локальные шрифты Raleway Regular и Bold, файл их подключения.
- `images/` — изображения и SVG из официальной заготовки.
- `styles/global.css` — базовые стили официальной заготовки.
- `styles/style.css` — стили страницы.
- `.github/workflows/tests.yml` — автоматические проверки из официальной заготовки для GitHub.

Использованы HTML5, CSS Grid, Flexbox и имена классов по БЭМ. Список лотов переносит дополнительные карточки на новую строку; высота карточек увеличивается при переполнении текстом.

## Проверка

Локально проверены загрузка шрифтов и изображений, открытие напрямую через `file://`, навигация к секциям, ширина страницы на экранах 1100 и 1440 px, перенос четвёртой карточки и увеличение высоты карточек при добавлении длинного текста. Автоматические проверки Практикума запускаются отдельно после загрузки в GitHub.
